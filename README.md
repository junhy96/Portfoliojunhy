# 게임 기획자 포트폴리오 (GitHub Pages)

모노톤 풀페이지 포트폴리오 사이트와 관리자 페이지. 서버 없이 **GitHub Pages**에서 무료로 동작합니다.

- **사이트** `/`: 스크롤하면 한 섹션씩 넘어갑니다(Home · About · Works · Contact). 섹션이 바뀔 때 배경 사진이 모핑되고, Works 썸네일을 누르면 PDF가 전체화면으로 열립니다.
- **관리자** `/studio/`: 게시판처럼 포트폴리오 PDF를 올리고, 썸네일을 고르고, 글을 수정·삭제·숨김·정렬합니다. 저장하면 GitHub 저장소에 바로 커밋되고 1~2분 뒤 사이트에 반영됩니다.

## 디자인

Editorial 스타일 하나로 운영합니다. 왼쪽 세로 레일, 01/04 카운터, 첫 화면 오른쪽의 큰 이름, 하단 유리 띠(최근 작업)가 있어요. About·Works는 간결한 구성을 Editorial 색·글꼴로 보여줍니다. 사이트가 열릴 때 큰 PORTFOLIO 글자가 펼쳐지며 나타납니다.

## Works (05 · Works)

카드는 그림 16:10 + 아래 제목줄 비율이에요. 처음엔 화면 가득(보통 PC 4열 × 2줄 + 오른쪽에 다음 열이 살짝) 보이고, 휠을 내리거나 마우스로 끌면 타임라인처럼 옆으로 밀려나요. 끝까지 가면 다음 페이지로 넘어가요. 휴대폰은 위아래로 스크롤해요. 위쪽 버튼으로 **문서 종류**(시스템 기획서·콘텐츠 기획서·레벨 디자인·밸런싱·데이터·UI·UX 기획서·역기획서·기타)별로 거를 수 있어요. 글을 쓸 때 문서 종류를 고르고, 목록은 **사이트 설정 → Works**에서 바꿔요. `sample: true`인 글은 '예시' 표시가 붙고, 관리자에서 수정해 저장하면 표시가 사라져요.

## 타임라인 (03 · Timeline)

교육·인턴십·경력·프로젝트·수상·자격증을 연도별로 가로로 길게 이어 보여 줘요. 페이지에 들어오면 밝은 선이 왼쪽부터 그어지며 항목이 차례로 펴지고, 휠·방향키·스와이프로 옆으로 넘기다 끝에 닿으면 다음 페이지로 넘어가요. 지금 보는 항목 하나만 앞으로 다가오며(slide-fwd) 크게 펼쳐져 설명과 주요 업무가 한 줄씩 나타나고, 나머지는 구분·기간·제목만 흐리게 보여요. 배경 사진을 넣은 항목을 보면 뒷배경이 그 사진으로 모핑돼요. 관리자 페이지 **사이트 설정 → 03 · Timeline**에서 배경 사진·구분·기간·제목·기관·설명·주요 업무(한 줄에 하나)를 입력해요. 기간 순서대로 자동 정렬돼요.

## 스킬 차트 (04 · Skills)

둥근 조각 하나가 스킬 하나예요. 숙련도 100이면 조각이 가득 차고, 조각에 마우스를 올리면(휴대폰은 탭) 살짝 커지면서 옆 말풍선에 숙련도와 설명이 나와요. 관리자 페이지 **사이트 설정 → 04 · Skills**에서 스킬 이름·숙련도(0~100)·아이콘·설명을 추가·수정·정렬합니다. 6~10개가 가장 보기 좋아요. 툴은 Simple Icons(CC0) 실제 로고, 공개 로고가 없는 PowerPoint·Excel·Word·C#은 직접 그린 글자 타일, 능력은 Lucide(ISC) 선 아이콘이며 모두 `js/icons.js`에 담았습니다.

## 배포 방법 (처음 한 번)

1. **저장소 만들기**: GitHub에서 New repository를 누릅니다.
   - 이름을 `내아이디.github.io`로 하면 주소가 `https://내아이디.github.io/`가 됩니다.
   - 다른 이름(예: `portfolio`)으로 하면 `https://내아이디.github.io/portfolio/`가 됩니다.
   - **Public**으로 만드세요. 무료 계정의 GitHub Pages는 공개 저장소만 지원합니다.
2. **파일 올리기**: zip을 풀고 `game-portfolio` 폴더 **안의** 파일과 폴더를 모두 저장소에 올립니다. 웹에서 “Add file → Upload files”로 끌어다 놓아도 되고, git으로 push해도 됩니다. `index.html`이 저장소 맨 위에 있어야 합니다. 숨김 파일 `.nojekyll`은 빠져도 동작합니다.
3. **Pages 켜기**: 저장소 → Settings → Pages → Source를 **Deploy from a branch**, Branch를 **main / (root)**로 정하고 Save합니다.
4. 1~2분 뒤 사이트 주소로 접속되는지 확인합니다.

## 관리자 페이지 쓰기

1. `사이트주소/studio/`로 들어갑니다. 사이트 어디에도 링크가 없으니 주소를 따로 기억해 두세요.
2. **GitHub 토큰 만들기** (한 번만)
   - https://github.com/settings/personal-access-tokens/new 를 엽니다.
   - Repository access: **Only select repositories** → 이 사이트 저장소만 고릅니다.
   - Permissions → Repository permissions → **Contents: Read and write**로 바꿉니다.
   - 만료 기간을 정하고 생성한 뒤 토큰(`github_pat_…`)을 복사합니다.
3. 관리자 페이지에 저장소(`아이디/저장소이름`), 브랜치(`main`), 토큰을 넣고 **연결하기**를 누릅니다.

토큰은 그 브라우저에만 저장됩니다. 이 토큰은 저장소에 쓸 수 있는 열쇠이므로 남에게 보여주지 마세요. 공용 PC에서는 “기억하기”를 끄고, 다 쓰면 **연결 해제**를 누르세요. 토큰이 유출됐다면 GitHub 설정에서 바로 삭제하면 됩니다.

### 포트폴리오 올리기
- **새 글 쓰기** → PDF를 끌어다 놓습니다. PDF에서 페이지 3장(첫 장, 1/3 지점, 2/3 지점)이 썸네일 후보로 자동 생성됩니다.
- 그중 하나를 고르거나 **이미지 업로드**로 원하는 썸네일을 직접 올립니다. 이미지는 자동으로 적당한 크기로 줄여서 저장됩니다.
- 제목·역할·장르·연도·태그·요약·상세 설명을 쓰고 **게시하기**를 누릅니다.
- 오른쪽 위 상태 표시가 “사이트 반영 중” → **“사이트에 반영됨”**으로 바뀌면 끝입니다.
- 글을 지우거나 썸네일·PDF를 바꾸면, 더 이상 쓰이지 않는 이전 파일은 저장소에서 자동으로 지워집니다.

### 처음에 바꿀 것
- **사이트 설정**에서 이름, 소개 문구, 연락처, 섹션 배경 사진 4장을 바꿉니다. 지금 들어 있는 실루엣 사진과 샘플 글 3개는 예시입니다.

## 지원처별 링크 (보여 줄 기획서·경력 고르기)

관리자 페이지 **링크 프리셋** 탭에서 게임 프리셋처럼 만들어요. ① 보여 줄 Works 기획서·타임라인 경력 카드를 눌러 켜고 끄고 ② 이름을 정한 뒤 ③ **프리셋 생성**을 누르면 바로 저장되고, **링크 복사**로 링크를 가져가면 돼요. 저장된 프리셋은 위쪽 슬롯에 쌓이고, 슬롯마다 링크 복사·불러오기(고치기)·삭제가 있어요. `사이트주소/?from=꼬리표`로 들어오면 체크한 것만 보이고, 접속 통계에도 그 꼬리표로 남아요. 꼬리표가 없거나 모르는 꼬리표면 전부 보여요. 새로 올린 기획서·경력은 모든 링크에 켜진 채로 들어가요.

- 숨긴 항목도 사이트 데이터(`data/site.json`)에는 남아 있어서, 기본 주소로 들어오면 보여요. 아예 안 보이게 하려면 게시판에서 비공개로 바꾸세요.

## 색감 (청록 회색 / 모노톤)

관리자 **사이트 설정 → 보기 설정 → 색감**에서 청록 회색(기본)과 모노톤 중에 골라요. 저장 전에 미리 보려면 주소 뒤에 `?tone=mono` 또는 `?tone=teal`을 붙여 열면 돼요. 바탕·그림자·사진 색보정·스킬 차트까지 함께 바뀌어요.

## 휴대폰에서도 PC 화면으로

관리자 페이지 **사이트 설정 → 보기 설정**의 **휴대폰에서도 PC 화면으로 보이기**를 켜면, 휴대폰으로 열어도 PC와 같은 화면(너비 1280 기준)으로 그려져요. 세로로 들고 있으면 '가로로 돌리면 더 크게 볼 수 있어요' 안내가 잠깐 떠요. 끄면 다시 휴대폰 화면으로 돌아가요.

## 접속 통계 (Supabase)

관리자 페이지 **접속 통계** 탭에서 다음을 볼 수 있습니다.
- 방문자·방문·페이지뷰·PDF 열람 수 (이전 기간 대비)
- 일별 방문자, 요일 × 시간대별 방문
- 기기와 유입 경로, 섹션 도달률, 많이 연 PDF
- 섹션·스타일·기기별 클릭 히트맵
- 최근 방문 목록

기록은 무료 DB 서비스 Supabase에 저장됩니다. 처음 한 번만 아래처럼 설정하세요. 관리자 페이지의 접속 통계 탭에도 같은 안내가 있습니다.

1. https://supabase.com 에 가입하고 새 프로젝트를 만듭니다.
2. **Authentication → Users → Add user**에서 통계를 볼 관리자 계정(이메일·비밀번호)을 만듭니다.
3. **SQL Editor**에 `supabase/analytics.sql` 내용을 붙여넣습니다. 맨 아래 이메일을 2번에서 만든 이메일로 바꾼 뒤 **Run**을 누릅니다.
4. **Project Settings → API Keys**에서 Project URL과 Publishable key(또는 anon key)를 복사합니다. 관리자 페이지 **사이트 설정 → 접속 통계**에 넣고 저장하세요.

**지원처별 링크**
- 관리자 페이지 접속 통계 탭의 **지원처별 링크 만들기**에 지원처 이름(예: `nexon`)을 넣으면 `사이트주소/?from=nexon` 링크가 만들어집니다. 복사해서 지원서에 넣으세요.
- 이 링크로 들어온 방문은 **지원처별 방문** 표에 지원처마다 방문자 수, 방문 수, 연 PDF, 마지막 방문 시간으로 나와요.
- 한 번 꼬리표 링크로 들어온 브라우저는 나중에 즐겨찾기 등으로 다시 들어와도 같은 지원처로 집계돼요.
- 꼬리표는 주소에 그대로 보입니다. 회사 이름이 보이는 게 싫으면 `a1`, `a2`처럼 정하고 메모 칸에 적어두세요.

**기록 방식**
- 이름·IP 같은 개인정보는 저장하지 않습니다. 브라우저마다 만든 무작위 ID, 기기 종류, 유입 사이트 주소, 본 섹션, 클릭 위치(화면 비율), 연 PDF 제목만 남깁니다.
- 브라우저의 추적 거부(Do Not Track) 설정을 켠 방문자는 기록하지 않습니다.
- 관리자 페이지를 연 브라우저도 기록하지 않습니다. 이 설정은 통계 화면 아래 스위치로 바꿀 수 있어요.
- 방문자는 기록을 남기기만 할 수 있고, 기록을 읽는 건 `admins`에 등록된 계정만 가능합니다.
- Supabase 무료 프로젝트는 일주일 넘게 아무 요청이 없으면 일시정지될 수 있습니다. 그럴 땐 Supabase 대시보드에서 다시 켜면 됩니다.

## 제한 사항

- **PDF 용량**: 파일당 최대 90MB입니다. 사이트에서 빨리 열리도록 40MB 이하를 권장합니다.
- **저장소 크기**: 1GB 이하를 권장합니다. 포트폴리오 PDF 수십 개 정도는 충분합니다.
- **반영 시간**: 저장 후 사이트에 보이기까지 1~2분 걸립니다.
- **비공개 글**: 사이트에서만 숨겨집니다. 공개 저장소라 GitHub에서는 파일이 보입니다.

## 내 컴퓨터에서 미리보기

```bash
python3 -m http.server 8000
```

그다음 http://localhost:8000 을 엽니다. 파일을 더블클릭해 `file://`로 열면 데이터를 불러오지 못하니 꼭 위 명령으로 여세요.

관리자 페이지에서 저장한 내용은 GitHub 저장소로 바로 들어갑니다. 내 컴퓨터에 받은 사본은 자동으로 바뀌지 않으니, git을 쓴다면 `git pull`로 받아오세요.

## 구조

```
index.html, css/, js/       공개 사이트
  js/morph.js               WebGL 모핑 (노이즈 변위 + 모노톤 보정)
  js/pdf-viewer.js          전체화면 PDF 뷰어 (pdf.js)
  js/analytics.js           접속 기록 (Supabase로 전송)
  js/timeline.js            가로 타임라인 (연혁)
  js/skills.js              스킬 차트 (둥근 조각 + 말풍선)
  js/icons.js               스킬 아이콘 (툴 로고 + Lucide)
css/theme-editorial.css     Editorial 디자인 (style.css 위에 덮어씀)
data/site.json              사이트 설정 + 포트폴리오 목록
uploads/                    PDF·썸네일·사진 (uploads/seed = 샘플)
studio/                     관리자 페이지 (github.js = 저장소 저장, stats.js = 접속 통계)
supabase/analytics.sql      접속 통계용 Supabase 설정 SQL
vendor/                     pdf.js (Pretendard·Inter Tight는 CDN)
.nojekyll                   GitHub Pages가 파일을 그대로 쓰도록 하는 설정
```
