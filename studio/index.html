GitHub 연결

글과 PDF는 GitHub 저장소에 바로 저장되고, 1~2분 뒤 사이트에 반영됩니다.

토큰은 어떻게 만드나요?
  1. GitHub → Fine-grained token 만들기를 엽니다.
  2. Repository access에서 Only select repositories → 이 사이트 저장소만 고릅니다.
  3. Permissions → Repository permissions → Contents를 Read and write로 바꿉니다.
  4. 만들어진 토큰(github_pat_로 시작)을 복사해 위에 붙여넣습니다.

토큰은 이 브라우저에만 저장되고 다른 곳으로 보내지지 않습니다. 공용 PC에서는 ‘기억하기’를 끄세요.

    접속 통계

    방문자 수, 접속 시간, 많이 본 섹션과 PDF, 클릭 위치를 봅니다. 시간은 이 컴퓨터의 시간대 기준입니다.

    지원처별 링크 만들기

    지원하는 곳마다 다른 링크를 주면, 이메일·PDF·카톡으로 열어도 어디서 봤는지 알 수 있어요

    꼬리표는 주소에 그대로 보여요. 회사 이름이 보이는 게 싫으면 a1, a2처럼 정하고 아래 메모에 적어두세요. 링크마다 보여 줄 기획서·경력까지 고르려면 사이트 설정 → 지원처별 링크에서 만드세요.

    처음 한 번만 설정하면 됩니다

    1. Supabase에 가입하고 New project로 프로젝트를 만듭니다. 무료 플랜이면 충분합니다.
    2. 왼쪽 메뉴 Authentication → Users → Add user로 통계를 볼 관리자 계정(이메일·비밀번호)을 만듭니다.
    3. SQL Editor에 아래 내용을 붙여넣고, 맨 아래 이메일을 2번에서 만든 이메일로 바꾼 뒤 Run을 누릅니다.
    4. Project Settings → API Keys에서 Project URL과 Publishable key(또는 anon key)를 복사해 사이트 설정 → 접속 통계 칸에 넣고 저장합니다.

    통계 보기 로그인

    Supabase에서 만든 관리자 계정으로 로그인하세요. 방문 기록은 이 계정만 볼 수 있습니다.

    로그인하지 않아도 예시 기록으로 대시보드 · 클릭 히트맵 · 접속 기록을 둘러볼 수 있어요.

    예시 데이터 · 실제 방문 기록이 아니에요. 진짜 기록은 로그인하면 보여요.
